# StayUp ブランド素材

出典は Claude Design プロジェクト [StayUp Identity](https://claude.ai/design/p/3f3e8201-0faf-4ca8-81f4-0d5d9adb8217)
の **5b “Stream Behind”**。アプリアイコンはこの案を採用している。

モチーフは 3 層。背面の水平な帯（夜のあいだ流れ続けるログ／処理）、中間の月（スリープ）、
前面の斜線（＝スリープを禁止する打ち消し線）。半透明の白の重なりだけで作られていて、
ストロークも影も使わない。重なった部分だけが明るくなることで奥行きが出る。

すべての素材は `generate.py` から生成する。デザイン上の `<mask>` や `transform="rotate()"` は
Icon Composer や Xcode の SVG サブセットで落ちる可能性があるため、三日月・カプセル・
くり抜きはすべて直線と円弧の塗りパスに展開済み。幾何は元デザインと一致することを確認している。

```sh
python3 design/branding/generate.py   # SVG をその場で再生成する
```

## app-icon/ — Icon Composer 用レイヤー

1024×1024。macOS 26 の Icon Composer は角丸マスク・スペキュラ・影・
ダーク／クリア／ティントの派生を自前で付けるので、ここには形だけを置いている。
**3 レイヤーはいずれも不透明な白一色**で、色と不透明度は Icon Composer 側で与える。
SVG と PNG の両方を入れてあるので、取り込みやすい方を使ってほしい。

| ファイル | Icon Composer 上の役割 | デザイン上の不透明度 |
| --- | --- | --- |
| `layer-1-bands.*` | 最背面 / ログ帯 | 26% |
| `layer-2-moon.*` | 中間 / 月 | 68% |
| `layer-3-slash.*` | 最前面 / 斜線 | 50% |

- レイヤーは下から `layer-1` → `layer-3` の順に重ねる。
- 右列の不透明度がデザインの意図した値。Icon Composer のインスペクタで
  この値を入れると `preview-composite` と同じ見えになる。3 枚とも白で
  重なりの明度差だけで奥行きを出しているので、この比率は崩さないほうがいい。
- 背景は `background.svg` にグラデーションを入れてあるが、レイヤーとして
  読み込むより Icon Composer のグラデーション設定に直接入れるほうが素直。
  150° の 2 stop で、始点 `#7368D4`・終点 `#172764`。
- 内容は 1024 のキャンバスに対して上下左右 161px のマージンを取っている
  （デザインの 108px タイル・inset 17px と同じ比率）。Icon Composer の
  セーフエリアに収まるので、そのまま読み込める。
- `preview-composite.*` は合成結果の確認用。ここにだけ色と不透明度を焼いてある。
  アイコンのビルドには使わない。

小さいサイズでの間引きはデザイン側で決まっている。Icon Composer は 1024 の
レイヤーから縮小するだけなので自動では効かない。必要なら手当てする:

- 60pt 以下 … 帯を 2 本に減らす（中央の帯を落とす）
- 32pt 以下 … 帯を全部落とす
- 16pt … 月のみ（`menu-bar/menubar-idle.svg` と同じ形）

## menu-bar/ — テンプレート画像

64×64、黒の単色。テンプレート画像として扱うので、色は macOS 側が塗り替える
（`NSImage.isTemplate = true`、または Asset Catalog の Render As: Template Image）。

| ファイル | 状態 |
| --- | --- |
| `menubar-idle.svg` | 抑止していない。月のみ |
| `menubar-active.svg` | 抑止中。月＋斜線 |

単色なので重なりを不透明度で分離できない。`menubar-active.svg` は斜線の両側に
2px ぶんの隙間を空けて月をくり抜いてあり、その隙間で層が読み分けられる。
2 つに割れた月と斜線の 3 パスから成るので、パスを個別に動かさないこと。

## logo/ — アプリロゴ

| ファイル | 用途 |
| --- | --- |
| `mark.svg` | マーク単体。`currentColor` で塗るので、SwiftUI なら `.foregroundStyle()` が効く |
| `lockup-light.svg` | マーク＋ワードマーク（明るい背景用） |
| `lockup-dark.svg` | 同（暗い背景用） |

ワードマークは Helvetica Neue Bold（600）・字送り -0.028em の `<text>` で、
アウトライン化していない。Helvetica Neue が無い環境では代替フォントに落ちるので、
配布物に埋め込むならアウトライン化してから使う。
